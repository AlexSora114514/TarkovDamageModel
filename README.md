📖 项目简介
本项目是一个面向《逃离塔科夫》(Escape from Tarkov) 的理想伤害计算终端，用于模拟子弹对护甲/插板的穿透、钝伤、综合伤害以及 TTK（Time To Kill） 排行。

通过对 弹药穿透力、护甲等级、插板耐久、重甲技能等级 等参数的建模，帮助玩家理性分析不同武器配置下的实际击杀效率，避免"玄学"讨论。

✨ 功能特性
🎯 首发命中穿透概率分析

综合考虑弹药穿深、护甲有效防护等级、稳穿临界值

🛡️ 护甲 / 防弹插板双层建模

支持插板（独立耐久）与甲皮（芳纶层）分别计算

记录插板损耗、甲皮损耗、剩余耐久

💥 击穿伤害 & 钝伤综合期望

区分"击穿伤害"与"钝伤"，给出综合期望伤害

🩸 逐发伤害模拟日志

输出每一发子弹的穿透率、击穿伤害、钝伤、胸部 HP 变化

⏱️ TTK 排行榜

仅统计全自动武器

每个口径取 RPM 最高的两把自动武器

按 TTK 升序排名，附带 BTK（Bullets To Kill）

🧠 重型护甲技能等级支持

0 ~ 51 级（51 = 精英），影响跳弹率与钝伤减免

🧮 核心公式
击穿伤害
text
击穿伤害 = 肉伤 × 弹丸数 × 有效护甲等级(穿透 ÷ (稳穿临界值 + 12.5), 0.6, 1.0)
其中 有效护甲等级(x, min, max) 表示将 x 限制在 [min, max] 区间内。

其他关键参数
参数	说明
有效防护等级	插板等级（示例中为 6 级钛板）
稳穿临界值 a	弹药稳穿该护甲所需的穿深阈值
插板耐久度	影响穿透率与击穿后剩余防护
甲皮耐久系数	如 6B45 芳纶层 18.75%
跳弹率	精英重甲（51 级）时为 20%
钝伤减免	随重甲技能等级提升

伤害模拟日志字段
字段	含义
子弹数	第几发
插板 / 甲皮	当前剩余耐久
插板稳穿临界值 / 甲皮稳穿临界值	当前状态下稳穿所需穿深
插板穿透率	该发实际穿透概率
击穿伤害 / 钝伤 / 综合伤害	该发造成的伤害
插板损耗 / 甲皮损耗	该发造成的耐久损失
胸部 HP	累计后剩余血量
TTK (毫秒)	累计击杀耗时
TTK 排行榜字段
排名	口径	子弹	武器	RPM	穿深	肉伤	TTK (毫秒)	BTK
排行榜条件：6 级钛板 / 满耐久 / 重甲 25 级
仅统计全自动武器，每颗子弹取其口径下 RPM 最高的两把自动武器。

🚀 使用方式
打开计算终端页面。

在 武器配置 中选择口径 / 弹药与武器平台。

在 护甲配置 中设置防弹插板等级、耐久、甲皮参数。

调整 重型护甲技能等级（0~51）。

📊 示例场景
配置：6 级钛板 / 满耐久 / 重甲 25 级
武器：某口径全自动武器（RPM 最高两把之一）
结果：输出该弹药对该护甲组合的 TTK 与 BTK，用于横向对比不同口径的击杀效率。

🛠️ 技术说明
纯前端实现（HTML / CSS / JavaScript）

所有计算在浏览器本地完成，无需后端

数据来源：游戏内实测 + 社区经验数据

计算模型为"理想化"模型，未考虑：

网络延迟

命中部位随机性（默认胸部）

移动 / 姿态修正

护甲损坏后的非线性衰减（部分简化）
